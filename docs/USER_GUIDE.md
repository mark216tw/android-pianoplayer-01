# 使用指南

## 1. 安裝與啟動

1. 安裝 `app-debug.apk`。
2. 開啟「鋼琴曲播放」。主畫面固定橫向並進入全螢幕。
3. 首次啟動若音譜庫為空，畫面會提示匯入 MusicXML。

## 2. 匯入樂譜

1. 按「↥ 匯入」。
2. 選擇 `.musicxml`、`.xml`、`.mxl` 或 JSON 包裝檔。
3. APP 會解析樂譜並顯示匯入摘要：
   - 音符數、聲部數、速度段、小節數
   - 已處理的記號與提醒
   - 若含多個樂器聲部，會提醒全部以鋼琴音色播放
4. 按「知道了」關閉摘要，再按 ▶ 播放。

匯入失敗時會顯示原因，例如檔案過大、非 `score-partwise`、JSON 缺少 `musicxml` 欄位，或樂譜沒有可播放音符。

## 3. 播放畫面

| 區域 | 說明 |
|---|---|
| 上方卷軸 | 音符由右往左捲動；固定播放游標、小節線與小節編號 |
| 下方鍵盤 | 依樂曲完整音域顯示；播放中的音即時亮起，起音有閃爍回饋 |
| 進度列 | 顯示曲名、目前時間／總長、可拖曳跳轉 |
| 狀態列 | 音符數、聲部數、目前 BPM、原譜小節、靜音聲部、音域 |

- 按 ▶／⏸ 切換播放與暫停。
- 按 ■ 停止並回到開頭。
- 按「速度」選擇 0.5×、0.75×、1×、1.25×、1.5×。
- 點擊卷軸可直接跳到該時間點。

## 4. 音色與聲部

按「⋮」開啟更多選項：

- **鋼琴音色**：Salamander 大鋼琴或合成鋼琴；可調整鋼琴音量與空間殘響。
- **聲部**：勾選要播放的聲部；取消勾選會靜音，設定會保存。
- **匯入摘要**：查看目前樂曲的解析結果與提醒。

## 5. 音譜庫

- 匯入成功的樂曲會自動加入音譜庫。
- 按「音譜庫」可：
  - ▶ 播放
  - ⋮ 改名／刪除
  - ↥ 匯入音譜
- APP 會記住上次選取的樂曲，下次啟動自動載入。

## 6. 設定

按右上角齒輪：

- 顯示模式：系統、淺色、深色。
- 主題色彩：六款預設色，或拖動 Hue 滑桿自訂。
- 設定會即時套用並保存。

## 7. 背景播放

播放時可切換到其他 APP、按 Home 或鎖屏，音樂會繼續播放。通知與鎖屏媒體控制提供播放／暫停／停止。其他 APP 取得音訊焦點時會暫停或降低音量。

## 8. 常見問題

- **看不到音符捲動**：請先確認已匯入樂譜且按下播放。
- **琴鍵很窄**：樂曲涵蓋完整 88 鍵時，鍵盤會壓縮以完整顯示；這是預期行為。
- **音色顯示「暫用合成」**：採樣仍在載入，稍候會自動切換。
- **匯入失敗**：確認檔案是 MusicXML，且沒有加密或超過 8 MB。
