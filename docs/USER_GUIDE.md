# 使用指南

## 1. 安裝與啟動

1. 安裝 `app-debug.apk`。
2. 開啟「鋼琴曲播放」。主畫面固定橫向並進入全螢幕。
3. 首次啟動若音譜庫為空，畫面會提示匯入 MusicXML。

## 2. 匯入樂譜

1. 按「音譜庫」→ 右上角「+」。
2. 選擇 `.musicxml`、`.xml`、`.mxl` 或 JSON 包裝檔。
3. APP 會解析樂譜並顯示匯入摘要：
   - 音符數、聲部數、速度段、小節數
   - 已處理的記號與提醒
   - 每個聲部實際分配的音色
4. 按「知道了」關閉摘要，會留在音譜庫；按該樂曲的「▶ 播放」開始。

匯入失敗時會顯示原因，例如檔案過大、非 `score-partwise`、JSON 缺少 `musicxml` 欄位、MIDI 檔，或樂譜沒有可播放音符。

## 3. 播放畫面

| 區域 | 說明 |
|---|---|
| 上方卷軸 | 音符由右往左捲動；固定播放游標、小節線與小節編號 |
| 下方鍵盤 | 依樂曲完整音域顯示；播放中的音即時亮起，起音有閃爍回饋 |
| 進度列 | 顯示曲名、目前時間／總長、可拖曳跳轉 |
| 狀態列 | 音符數、聲部數、目前 BPM、原譜小節、靜音聲部、音域 |

- 按 ▶／⏸ 切換播放與暫停。
- 按 ■ 停止並回到開頭。
- 按「速度」選擇 0.5×、0.75×、1×、1.25×、1.5×。
- 拖曳下方進度列可跳到該時間點。水平拖曳上方卷軸時，整條音符與小節線會跟手移動，放開後跳到對應時間；點擊卷軸不會跳轉。

## 4. 音色與聲部

按「⋮」開啟更多選項：

- **音色**：自動（依樂譜）、Salamander 大鋼琴、小提琴或合成鋼琴；可調整小提琴音量與空間殘響。
  - 自動模式會依 MusicXML 的聲部名稱、`score-instrument` 與 `midi-program` 分配鋼琴或小提琴；無法辨識的樂器改用鋼琴並在匯入摘要提醒。
  - 中提琴、大提琴與低音提琴會使用小提琴取樣；低音預設以移調小提琴補位，可在「弦樂低音使用小提琴（移調）」切換回鋼琴。
  - 「小提琴音量」滑桿預設 75%，可調整小提琴／跳弓與鋼琴的相對音量。
  - 混合樂譜會同時載入鋼琴與小提琴音色；手動選音色可覆蓋自動分配。
  - 小提琴長音使用 VSCO 2 CE Arco Vib；音長小於 0.35 秒且 MIDI 21–96 的音符自動改用 Spiccato 跳弓。
  - 小提琴聲部的 MIDI 21–54 由鋼琴低音補位；中提琴／大提琴可改用移調小提琴。85–96 短音使用跳弓，97 以上使用長弓；高音會隨音高增加高頻衰減。
  - 小提琴長弓與跳弓忽略鋼琴延音踏板，放開音符後會快速衰減；低音鋼琴仍保留鋼琴踏板行為。
- **聲部**：勾選要播放的聲部；取消勾選會靜音，設定會保存。
- **匯入摘要**：查看目前樂曲的解析結果與提醒。

## 5. 音譜庫

- 匯入成功的樂曲會自動加入音譜庫，並停留在音譜庫；只加入清單，不中斷目前播放。
- 每首樂曲的作曲者與時長顯示在同一列，聲部樂器名稱顯示在下一行；兩者都不加欄位標題。
- 搜尋框可比對樂曲名稱、作曲者與樂器名稱。
- 點擊樂曲名稱可查看該曲的匯入摘要；只有「▶ 播放」按鈕會開始播放，點卡片其他位置不會播放。
- 按「音譜庫」可：
  - ▶ 播放
  - ⋮ 刪除
  - 右上角「+」匯入音譜
- APP 會記住上次選取的樂曲，下次啟動自動載入。

## 6. 設定

按右上角齒輪：

- 顯示模式：系統、淺色、深色。
- 主題色彩：六款預設色，或拖動 Hue 滑桿自訂。
- 設定會即時套用並保存。

## 7. 背景播放

播放時可切換到其他 APP、按 Home 或鎖屏，音樂會繼續播放。通知與鎖屏媒體控制提供播放／暫停／停止。其他 APP 取得音訊焦點時會暫停或降低音量。

## 8. 常見問題

- **看不到音符捲動**：請先確認已匯入樂譜且按下播放。
- **琴鍵很窄**：樂曲涵蓋完整 88 鍵時，鍵盤會壓縮以完整顯示；這是預期行為。
- **音色顯示「暫用合成」**：採樣仍在載入，稍候會自動切換。
- **小提琴低音或極高音不自然**：Arco 取樣原始音域為 G3–C7、跳弓為 G3–C6，超出部分以移調方式補滿；中提琴／大提琴低音可在音色設定切換是否使用移調小提琴。
- **匯入失敗**：確認檔案是 MusicXML，且沒有加密或超過 8 MB。
