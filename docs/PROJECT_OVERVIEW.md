# 專案說明

## 1. 定位

「鋼琴曲播放」是一款離線 Android 鋼琴樂曲播放器。使用者匯入 MusicXML 樂譜後，APP 以兩種同步視覺呈現演奏：

1. **橫向鋼琴卷軸**：時間由右往左流動，音符依音高排列。
2. **完整音域鍵盤**：自動顯示樂曲最低音到最高音，播放時即時亮鍵。

APP 的目標是「聆聽＋觀看」，不是電子琴或錄音工具。

## 2. 功能範圍

| 類別 | 內容 |
|---|---|
| 匯入 | `.musicxml`、`.xml`、`.mxl`、JSON 包裝格式；內容驗證與大小限制 |
| 視覺 | 橫向卷軸、播放游標、小節線與編號、左右手分色、發光音符、完整音域鍵盤、自適應音名 |
| 播放 | 播放／暫停、停止、進度跳轉、0.5–1.5 倍速、BPM 與小節顯示 |
| 音色 | 自動依 MusicXML 聲部分配、Salamander 大鋼琴三力度層、VSCO 2 CE 小提琴長弓與跳弓、中提琴／大提琴低音移調、低音鋼琴補位、高音柔化、逐鍵 K 加權響度校正、合成鋼琴、小提琴音量、空間殘響 |
| 聲部 | 聲部靜音與保存 |
| 音譜庫 | 匯入、播放、作曲者與聲部樂器顯示、刪除、上次選取還原 |
| 背景 | 前景播放服務、通知、MediaSession、鎖屏控制、音訊焦點、WakeLock |
| 外觀 | 全螢幕橫向、系統／淺色／深色、六款主題色、自訂 Hue |
| 離線 | 無帳號、無網路、無麥克風權限 |

## 3. 非目標

- 不使用麥克風錄音。
- 不提供手動彈奏、多指和弦、滑奏或力度感應。
- 不提供節拍器、錄製倒數或 BPM 錄音設定。
- 不匯出 MusicXML、MIDI 或音訊檔。
- 不支援 MIDI、MP3、WAV 或線上樂譜服務。

## 4. 已知限制

- 88 鍵全音域在窄螢幕上會壓縮琴鍵；APP 會自動省略個別音名，只保留 C 音基準。
- 卷軸以音高垂直排列，與下方水平鍵盤不是幾何對齊；兩者以「同一個音高」同步亮起。
- 背景播放與鎖屏控制需真機驗收。
- 採樣音色載入完成前會暫用合成音色。
- 小提琴 Arco 原始音域為 G3–C7、Spiccato 為 G3–C6；MIDI 21–54 由鋼琴低音補位（中提琴／大提琴可改用移調小提琴），21–96 短音可用跳弓，97 以上使用長弓並套用高頻衰減。
- 鋼琴與小提琴混合譜需同時載入兩套音色，記憶體約 82 MB，低記憶體裝置需真機驗收。
- 中提琴／大提琴以移調小提琴取代鋼琴，低音音色仍需真機 A/B；可在音色設定切換回鋼琴。
- 純文字 `ritard.`／`accel.` 不會自動猜測變速；其他簡化內容會列在匯入摘要。

## 5. 發展方向

- 卷軸可視時間窗與「減少動態效果」設定。
- A-B 循環與段落重播。
- 內建範例樂曲與首次啟動引導。
- 左右手圖例與聲部色彩自訂。
- 低階裝置效能模式。
