# 疑難排解

## 1. 匯入失敗

| 訊息 | 處理 |
|---|---|
| 樂譜檔案過大（上限 8 MB） | 移除內嵌圖片或改用 MXL 壓縮 |
| 目前支援 score-partwise MusicXML | 確認檔案不是 `score-timewise` 或其他格式 |
| JSON 檔案必須包含 musicxml 欄位 | 確認 JSON 內有非空字串 `musicxml` |
| MXL 缺少 META-INF/container.xml | 重新以 MuseScore 等工具匯出 MXL |
| 此樂譜沒有可播放的音符 | 確認樂譜有固定音高音符，不是只有打擊樂 |
| 不支援 MIDI 樂譜 | 目前只支援 MusicXML；請以 MuseScore 等工具匯出 MusicXML 或 MXL |
| 不支援 XML 實體或非 UTF-8 編碼 | 以 UTF-8 重新儲存 XML |

## 2. 沒有聲音

1. 確認已按 ▶，且進度條有前進。
2. 確認媒體音量。
3. 查看畫面左上音色狀態；若顯示「暫用合成」，等待採樣載入。
4. 自動模式依 MusicXML 聲部名稱與 `midi-program` 分配音色；若聲部未正確判定，匯入摘要會顯示實際分配，手動選音色可覆蓋。
5. 小提琴聲部 MIDI 21–54 使用鋼琴低音，21–96 短音可使用跳弓，97 以上使用長弓；中提琴／大提琴低音預設使用移調小提琴，可在音色設定關閉。
6. 小提琴短音會自動跳弓、長音使用長弓；若仍覺得拖，確認跳弓與低音鋼琴庫已載入（音色狀態會顯示「跳弓／低音鋼琴」）。
7. 小提琴長弓與跳弓在放開音符後會快速衰減，且不受樂譜延音踏板影響；低音鋼琴仍保留踏板。
8. 藍牙／耳機中斷可能觸發暫停，重新按播放。
9. 若出現「音訊無法啟動」，重新開啟 APP。

## 3. 卷軸或鍵盤顯示異常

- 音符超出音域：APP 會依實際音符自動調整；若仍異常，回報樂譜檔案。
- 88 鍵太窄：屬預期行為；可改用較寬的裝置或橫向全螢幕。
- 卷軸不動：確認正在播放，且曲目有音符。
- 亮鍵與卷軸不同步：回報裝置型號與樂譜；通常與音訊裝置延遲有關。

## 4. 背景播放

- 播放時切到其他 APP 應持續播放。
- 若被系統停止，確認省電模式未限制前景服務。
- 其他 APP 播放音訊時，本 APP 可能暫停或降低音量，屬音訊焦點行為。

## 5. 音譜庫

- 找不到樂曲：確認匯入成功，且檔案未被清除。
- 刪除後無法復原，請先確認。

## 6. 測試環境

Robolectric 測試使用 API 26／29／35，不需要 JDK 21。若自行將測試 SDK 改為 36，才需要以 JDK 21 執行測試。

## 7. 桌面圖示未更新

- Android 啟動器會快取圖示；安裝新版後若仍顯示舊圖示，請重新安裝 APK。
- 可重新啟動啟動器、切換主題，或清除啟動器快取後再確認。
- 圖示背景目前為冷色系漸層；前景與單色圖示皆已移除上方裝飾。
